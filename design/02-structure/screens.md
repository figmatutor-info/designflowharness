# Screens

**작성일:** 2026-09-18 (수정: 2026-09-18 — 하단 탭바 등 가정 항목 확정 반영)
**대상:** 허들링 앱 (AI 실무 학습 플랫폼 + 멤버 자산 마켓)
**근거:** PRD.md §5 시연 범위 5개 화면, design/01-references/analysis.md
**총 화면:** 5개

PRD §4 앱 정보 구조에는 8개 섹션(홈/무료 학습자료/유료 멤버 자료실/스킬 라이브러리/미션/내 학습/내 자산/허들링 픽)이 있으나, §5에서 시연 범위를 5개 화면(홈/스킬 라이브러리/미션 상세/내 자산/허들링 픽)으로 명시했으므로 이 5개만 정의한다.

**확정: 하단 탭바 채택.** 탭 4개 — 홈 / 스킬 라이브러리 / 내 자산 / 허들링 픽 (analysis.md 컴포넌트-3 언더라인 탭 네비게이션, 클래스101 003 하단 탭바 패턴 참조). 미션 상세는 탭바 대상이 아니며, 오직 홈의 이번 달 미션 카드를 통해서만 진입한다 (탭바 없음).

## 화면 1 · 홈

### 기본 정보

- **목적:** 유료 멤버 진입 시 현재 상태 확인 (PRD §5 화면 1)
- **진입 경로:** 앱 시작 시 (가정: 로그인 화면은 시연 범위 외이므로 진입 직후로 가정). 이후 재진입은 하단 탭바 첫 번째 탭("홈")을 통해 확정된다.
- **primary 액션:** 이번 달 미션 카드 탭 → 미션 상세 이동 (PRD §5 명시)
- **부가 액션:**
  - 최근 학습한 자료 항목 탭 (가정: 대상 화면은 유료 멤버 자료실이며 시연 범위 외)
  - 최근 스킬 카드 항목 탭 (가정: 대상 화면은 스킬 카드 상세이며 시연 범위 외)
  - 알림 확인 (PRD §6에 따라 알림 목록 화면은 시연 범위 외)
  - 하단 탭바로 스킬 라이브러리 / 내 자산 / 허들링 픽 이동 (확정)
- **데이터:** 이번 달 미션(진행률, D-day) + 최근 학습 자료 목록 + 최근 스킬 카드 목록 + 내 자산 진행 상황 요약 + 알림 목록
- **필요 상태:** default, loading, empty(최근 학습 자료·최근 스킬 카드가 없는 신규 멤버 상태)
- **이미지 자리:** 최근 학습 자료 썸네일 (개수 미정, 가정: 1:1 정사각), 최근 스킬 카드 썸네일 (개수 미정, 가정: 1:1 정사각). 두 썸네일 모두 **확정: 슬롯 안에 이미지를 fit(contain, 잘라내지 않음)으로 배치하고, 슬롯 배경은 파스텔톤 하늘색으로 깐다.** 구체 색상 값(hex/토큰)은 Phase 3(design-rules)에서 결정한다. 히어로 이미지는 PRD에 명시 없음 — analysis.md 시각-4(마스코트 히어로)는 브랜드 톤 불일치로 채택하지 않음.

### 구성 요소 (상단 → 하단)

1. 이번 달 미션 카드 (진행률, D-day)
2. 최근 학습한 자료
3. 최근 스킬 카드
4. 내 자산 진행 상황 요약
5. 알림 (미션 마감, 피드백 등)
6. **하단 탭바** (홈 / 스킬 라이브러리 / 내 자산 / 허들링 픽 — "홈" 활성 표시) — 확정

### 레퍼런스 매칭

- **시각 패턴 #3** (옅은 회색 배경 위 화이트 라운드 카드 대비) — 플랭/말해보카에서 발견. 이번 달 미션 카드에 적용.
- **컴포넌트 패턴 #2** (진행률 바 · 단순 채움형, 말해보카 방식) — 이번 달 미션 카드의 진행률·D-day 표기에 적용.

- **컴포넌트 패턴 #3** (언더라인 탭 네비게이션, 클래스101 003 하단 탭바) — 하단 탭바(홈/스킬 라이브러리/내 자산/허들링 픽) 활성 표시에 적용.

## 화면 3 · 미션 상세

### 기본 정보

- **목적:** 이번 달 미션 확인 및 제출 (PRD §5 화면 3)
- **진입 경로:** 홈 화면 이번 달 미션 카드 탭 (primary 액션 경로, 화면 1 참조)이 유일한 진입 경로다. **확정: 이 화면에는 하단 탭바가 없다** — 뒤로가기로만 홈으로 복귀한다.
- **primary 액션:** 제출하기 (파일 첨부 + 설명 작성) (PRD §5 명시)
- **부가 액션:**
  - 관련 스킬 카드 추천 항목 탭 → 스킬 라이브러리 이동 (가정: 스킬 라이브러리 화면으로 이동, 또는 스킬 카드 상세면 시연 범위 외)
  - 이전 피드백 기록 확인
- **데이터:** 미션(제목, 설명, 마감일, 요구 산출물) + 제출(Submission: status, feedback) + 관련 스킬 카드 목록 (PRD §8 Mission/Submission 데이터 모델 참조)
- **필요 상태:** default, loading, submitting(제출 후 AI/운영자 검수 대기 — analysis.md AI 로딩 모달 패턴), error(제출 실패)
- **이미지 자리:** 없음 (PRD §5 구성 요소는 텍스트·상태·리스트 중심이며 이미지 요소 언급 없음)

### 구성 요소 (상단 → 하단)

1. 미션 제목, 설명, 마감일
2. 요구 산출물 (예: AI 자동화 자산 1개 + 실제 적용 사례 1개)
3. 관련 스킬 카드 추천
4. 제출 상태 (작성 중 / 제출 완료 / 피드백 대기 / 승인)
5. 이전 피드백 기록

**하단 탭바 없음** — PRD §5 미션 상세는 시연 범위 5개 화면 중 유일하게 탭바 진입 대상이 아니며, 홈의 미션 카드에서만 진입하는 단일 목적 화면으로 확정한다.

**확정: 제출 폼과 재제출.** 파일 첨부 + 설명 작성 폼은 별도 화면이 아니라 이 미션 상세 화면 내 상태 전환(제출하기 버튼 탭 시 폼 노출)으로 처리한다. 피드백을 받은 뒤 재제출할 때도 동일한 "제출하기" 버튼을 다시 사용한다.

### 레퍼런스 매칭

- **UX 패턴 #2** (상태별 섹션 구분 리스트) — 클래스101에서 발견. 제출 상태 및 이전 피드백 기록 나열에 적용.
- **UX 패턴 #3** (AI 처리 로딩 모달) — 차란에서 발견. 제출 후 검수 대기 상태(submitting)에 적용.
- **컴포넌트 패턴 #2** (진행률 바 · 단순 채움형) — 마감일/진행 표기에 적용.
- **컴포넌트 패턴 #4** (Sticky 하단 풀폭 CTA 버튼) — 차란/플랭에서 발견. "제출하기" 버튼에 적용.
- **컴포넌트 패턴 #5** (카드형 아이템 로우) — 클래스101에서 발견. "관련 스킬 카드 추천" 리스트에 적용.

### 필요 컴포넌트

- SectionHeader (상태별 구분)
- Modal (dimmed 배경 + 중앙 로딩 카드)
- ProgressBar
- BottomCTA (sticky 풀폭, 제출하기/재제출 공용)
- 아이템 로우 (관련 스킬 카드 추천)

## 화면 4 · 내 자산

### 기본 정보

- **목적:** 내가 만든 자료 관리, 판매 신청 (PRD §5 화면 4)
- **진입 경로:** 홈 화면 "내 자산 진행 상황 요약" 카드 탭, 또는 하단 탭바 세 번째 탭("내 자산")에서 진입 (확정).
- **primary 액션:** 새 자산 등록 (PRD §5 명시. 단 "자산 등록 폼" 화면 자체는 PRD §6에 따라 시연 범위 외이며, 이 화면에서는 등록 진입점만 다룬다)
- **부가 액션:**
  - 필터 전환 (전체 / 비공개 / 멤버 공개 / 판매 신청 중 / 판매 중)
  - 자산 카드 탭 → 자산 상세 (가정: PRD §6에 따라 시연 범위 외)
  - 하단 탭바로 홈 / 스킬 라이브러리 / 허들링 픽 이동 (확정)
- **데이터:** Asset 목록(썸네일, 제목, 카테고리, 상태, visibility, review_status) + 판매 수익 요약 (PRD §8 Asset 데이터 모델 참조)
- **필요 상태:** default, loading, empty(등록된 자산 없음)
- **이미지 자리:** 자산 목록 썸네일 (개수 미정, 가정: 1:1 정사각 — PRD §8 Asset.preview 필드 참조). **확정: 슬롯 안에 이미지를 fit(contain, 잘라내지 않음)으로 배치하고, 슬롯 배경은 파스텔톤 하늘색으로 깐다.** 구체 색상 값은 Phase 3(design-rules)에서 토큰으로 결정한다.

### 구성 요소 (상단 → 하단, PRD §5 순서)

1. 자산 목록 (썸네일, 제목, 카테고리, 상태)
2. 필터: 전체 / 비공개 / 멤버 공개 / 판매 신청 중 / 판매 중
3. 새 자산 등록 버튼
4. 각 자산 카드: 상태 뱃지, 판매 신청 시 검수 진행 상황
5. 판매 수익 요약
6. **하단 탭바** (홈 / 스킬 라이브러리 / 내 자산 / 허들링 픽 — "내 자산" 활성 표시) — 확정

**가정 (배치 관련, 유지):** PRD §5 원문의 나열 순서(자산 목록 → 필터 → 등록 버튼 → 카드 상세 요소 → 수익 요약)를 그대로 따르되, 실제 화면 배치 상단→하단 순서는 "필터 → 자산 목록(카드별 상태뱃지 포함) → 판매 수익 요약", "새 자산 등록"은 화면 상단 또는 sticky 하단 버튼으로 배치하는 것이 analysis.md 컴포넌트-4(sticky CTA) 패턴과 일치. 최종 배치는 Phase 3에서 확정.

**확정: 판매 신청 경로.** 판매 신청 액션 자체는 자산 상세(시연 범위 외) 화면에서 이루어지며, 이 내 자산 화면에서는 판매 신청 이후의 상태 전환 결과(판매 신청 중 → 판매 중)만 표시한다.

**확정: 산출물 자산화 시작점.** 승인된 미션 산출물을 내 자산으로 전환하는 것은 자동 생성이 아니라, 이 화면의 "새 자산 등록"(primary 액션)을 사용자가 직접 탭해 수동으로 시작한다.

### 레퍼런스 매칭

- **UX 패턴 #2** (상태별 섹션 구분 리스트) — 클래스101에서 발견. 전체/비공개/멤버공개/판매신청중/판매중 필터 결과 표시에 적용.
- **컴포넌트 패턴 #3** (언더라인 탭 네비게이션) — 상태 필터 탭 및 하단 탭바에 적용.
- **컴포넌트 패턴 #1** (이미지 코너 상태뱃지 + pill) — 차란에서 발견. 자산 카드의 검수 진행 상황 표시에 적용.
- **컴포넌트 패턴 #4** (Sticky 하단 풀폭 CTA 버튼) — "새 자산 등록" 버튼에 적용.
- **UX 패턴 #3** (AI 처리 로딩 모달) — 등록 흐름 내 AI 자동 태깅·검수 진행 표시에 적용 (차란 007/009 참고).

### 필요 컴포넌트

- Tab (언더라인 활성, 상태 필터)
- AssetCard (썸네일 + Badge/Pill + 검수 진행 상황)
- BottomCTA (새 자산 등록)
- Modal (AI 자동 태깅/검수 로딩)
- TabBar (하단 4탭)

## 화면 5 · 허들링 픽

### 기본 정보

- **목적:** 검증된 멤버 자산 마켓 (구매) (PRD §5 화면 5)
- **진입 경로:** 하단 탭바 네 번째 탭("허들링 픽")에서 진입 (확정).
- **primary 액션:** 픽 카드 탭 → 상세 페이지 (PRD §5 명시. "상세 페이지" 자체는 PRD §6에 따라 시연 범위 외)
- **부가 액션:**
  - 카테고리 필터
  - 정렬 (최신순 / 인기순 / 가격순)
  - 검색바 탭 → 검색 진입. **확정: 스킬 라이브러리와 동일하게 별도 화면이 아니라 화면 내 상태 전환(리스트 오버레이)으로 처리한다.**
  - 하단 탭바로 홈 / 스킬 라이브러리 / 내 자산 이동 (확정)
- **데이터:** 픽 카드 목록(이미지, 제목, 제작자, 가격, 카테고리)
- **필요 상태:** default, loading, empty(필터·검색 결과 없음)
- **이미지 자리:** 픽 카드 썸네일 (개수 미정, 가정: 세로형 — analysis.md 차란 008 PDP 이미지 참고). **확정: 슬롯 안에 이미지를 fit(contain, 잘라내지 않음)으로 배치하고, 슬롯 배경은 파스텔톤 하늘색으로 깐다.** 구체 색상 값은 Phase 3(design-rules)에서 토큰으로 결정한다.

### 구성 요소 (상단 → 하단, PRD §5 순서)

1. 검색바
2. 카테고리 필터
3. 정렬 (최신순 / 인기순 / 가격순)
4. 픽 카드 그리드 (각 카드: 이미지, 제목, 제작자, 가격, 카테고리)
5. **하단 탭바** (홈 / 스킬 라이브러리 / 내 자산 / 허들링 픽 — "허들링 픽" 활성 표시) — 확정

**참고:** "카드 탭 → 상세 페이지 (미리보기, 포함 내용, 사용 조건, 구매 버튼)"는 PRD §5에 함께 서술되어 있으나, 상세 페이지는 PRD §6 시연 대상 외 화면 목록("허들링 픽 상세")에 해당하므로 이 화면 정의에는 그리드까지만 포함한다.

### 레퍼런스 매칭

- **UX 패턴 #4** (랭크드 인기 검색어 + 확장 미리보기) — 클래스101/프립에서 발견. 검색바 탭 시 화면 내 상태 전환(리스트 오버레이)에 적용.
- **컴포넌트 패턴 #3** (언더라인 탭 네비게이션) — 카테고리·정렬 및 하단 탭바에 적용.
- **컴포넌트 패턴 #1** (이미지 코너 상태뱃지, 컨디션 pill, 판매자 row) — 차란 008 PDP 패턴 참고. 픽 카드의 제작자·가격·카테고리 표기에 적용.
- **컴포넌트 패턴 #4** (Sticky 하단 풀폭 CTA 버튼) — 상세 페이지(시연 범위 외)의 "구매하기" 버튼에 적용 예정으로 analysis.md에 기록됨. 이 화면(그리드) 자체에는 sticky CTA 없음.

### 필요 컴포넌트

## 화면 흐름 요약

```
홈 (①) [탭바: 홈 활성]
├─ 이번 달 미션 카드 탭 (primary) → 미션 상세 (③, 탭바 없음)
├─ 최근 학습한 자료 탭 → (시연 범위 외: 유료 멤버 자료실)
├─ 최근 스킬 카드 탭 → (시연 범위 외: 스킬 카드 상세)
├─ 내 자산 진행 상황 요약 탭 → 내 자산 (④)
└─ 하단 탭바 → 스킬 라이브러리 (②) / 내 자산 (④) / 허들링 픽 (⑤)

스킬 라이브러리 (②) [탭바: 스킬 라이브러리 활성]
├─ 검색바 탭 → 화면 내 상태 전환(인기 검색어 리스트)
├─ 스킬 카드 탭 (primary) → (시연 범위 외: 스킬 카드 상세)
└─ 하단 탭바 → 홈 (①) / 내 자산 (④) / 허들링 픽 (⑤)

미션 상세 (③) [탭바 없음 — 홈에서만 진입]
├─ 제출하기 (primary, 화면 내 상태 전환) → 제출 상태 전환 (submitting → AI 검수 대기 모달)
├─ 관련 스킬 카드 추천 탭 → 스킬 라이브러리 (②) [가정: 진입 트리거]
└─ 뒤로가기 → 홈 (①)

내 자산 (④) [탭바: 내 자산 활성]
├─ 새 자산 등록 (primary) → (시연 범위 외: 자산 등록 폼) → 등록 후 "비공개" 상태로 복귀
├─ 자산 카드 탭 → (시연 범위 외: 자산 상세, 판매 신청은 여기서 처리)
└─ 하단 탭바 → 홈 (①) / 스킬 라이브러리 (②) / 허들링 픽 (⑤)

허들링 픽 (⑤) [탭바: 허들링 픽 활성]
├─ 검색바 탭 → 화면 내 상태 전환(인기 검색어 리스트)
├─ 픽 카드 탭 (primary) → (시연 범위 외: 허들링 픽 상세)
└─ 하단 탭바 → 홈 (①) / 스킬 라이브러리 (②) / 내 자산 (④)
```

## 컴포넌트 목록 (전체 화면 통합)

analysis.md "필요 컴포넌트" 목록(전체 리스트) 기준으로 5개 화면에서 실제 사용되는 것만 정리:

- **Button** (primary/outline, sticky bottom 풀폭 variant 포함)
- **Card** (미션 진행률 카드, 아이템 로우형)
- **SkillCard** / **AssetCard** / **PickCard** (이미지+제목+상태뱃지 variant. 이미지 슬롯은 fit(contain) + 파스텔 하늘색 배경 공통 규칙 적용, 색상 토큰은 Phase 3에서 결정)
- **Badge/Pill** (상태뱃지 코너형, 카테고리/난이도/무료·유료 pill형)
- **ProgressBar** (단순 채움형 + 분수)
- **SearchBar** + 랭크드 검색어 리스트 (화면 내 상태 전환)
- **Tab** (언더라인 활성 표시 — 필터/정렬용)
- **TabBar** (하단 4탭: 홈 / 스킬 라이브러리 / 내 자산 / 허들링 픽 — 미션 상세에는 없음)
- **Modal** (dimmed 배경 + 중앙 로딩 카드, AI 검수/분석 대기용)
- **SectionHeader** (상태별 리스트 구분용)
- **EmptyState**
- **LoadingSpinner**
