## 화면 1 · 홈

### 기본 정보

- **목적:** 유료 멤버가 앱에 진입했을 때 이번 달 학습 현황과 자산 진행 상황을 한눈에 확인한다.
- **진입 경로:** 앱 실행 시 기본 진입 / 탭바 "홈" 탭
- **주요 요소 (레이아웃 순서):**
  1. 이번 달 미션 카드 — 진행률(%)을 카드 최상단 수치로, D-day 배지를 카드 우측 상단에 배치
  2. 최근 학습한 자료 리스트 (가로 스크롤 또는 세로 3~4행)
  3. 최근 스킬 카드 (가로 스크롤 카드 행)
  4. 내 자산 진행 상황 요약 카드 (상태별 개수 요약)
  5. 알림 영역 (미션 마감 임박, 피드백 도착 등 리스트)
- **Primary 액션:** 이번 달 미션 카드 탭 → 화면 3(미션 상세)로 이동
- **부가 액션:**
  - 최근 학습 자료 항목 탭 (시연 범위 밖 화면으로 연결 — 구조만 유지)
  - 최근 스킬 카드 탭 → 화면 2 관련 화면으로 이동
  - 알림 항목 탭 (시연 범위 밖 — 구조만 유지)
  - 탭바를 통한 화면 2/4/5 이동
- **데이터 종류:** 미션 카드(진행률·D-day) + 학습자료 목록 + 스킬 카드 목록 + 자산 요약 + 알림 목록
- **필요 상태:** default, loading, empty (신규 유료 멤버로 미션 미배정·자산 없음 시)

## 화면 흐름 요약

```
홈 (①)
├─ 이번 달 미션 카드 탭 → 미션 상세 (③)
├─ 최근 스킬 카드 탭 → 스킬 라이브러리 (②)
└─ 탭바 이동 → 스킬 라이브러리(②) / 내 자산(④) / 허들링 픽(⑤)

스킬 라이브러리 (②)
└─ 스킬 카드 탭 → (스킬 카드 상세, 시연 범위 밖)

미션 상세 (③)
├─ 제출하기 → 제출 폼(submitting) → 상태 배지 전환(제출완료→피드백대기→승인)
├─ 승인 시 → 내 자산 (④) 에 자산 반영
└─ 관련 스킬 카드 탭 → 스킬 라이브러리 (②)

내 자산 (④)
├─ 새 자산 등록 → (등록 폼, 시연 범위 밖)
└─ 자산 카드 판매 신청 → 상태 배지 "판매 신청 중" 전환

허들링 픽 (⑤)
└─ 픽 카드 탭 → (픽 상세, 시연 범위 밖 참고 화면 · BottomActionBar 3분할)
```

## 컴포넌트 목록 (전체 화면 통합)

analysis.md "필요 컴포넌트" 목록을 그대로 사용한다.

- **Card** — 미션형 / 스킬형 / 자산형 (①②③④⑤ 공통)
- **Badge** — 시간형(D-day soft·danger 전환) / 분류형 / 속성형 (①③④⑤)
- **Chip** — 필터 · 선택 filled (②④⑤)
- **SearchBar** (②⑤)
- **SegmentedControl** — 난이도(②), 정렬(⑤)
- **Button** — primary filled / secondary outlined / ghost / disabled (③④⑤)
- **ListRow** — 썸네일 + 제목 + 메타 + 우측 액션 (①②④)
- **ProgressIndicator** — 수치 병기 (①)
- **EmptyState** — 문장 한 줄형 (①②④⑤)
- **Input** — 라벨 내장 filled, 2열 그리드 (④ 등록 폼, 시연 범위 밖 참고)
- **Tabs** — 언더라인형 (시연 범위 밖, 통합 검색 대비 구조로만 유지)
- **BottomCTA** — primary + ghost 2층 (③)
- **TabBar** — 하단 탭바 (①②④⑤ 공통 내비게이션)
- **SpecBox** — 좌 라벨 / 우 값 2열, 회색 filled (③ 요구 산출물, ⑤ 참고 픽 상세)
- **PriceBlock** — 금액 + 부가 안내 한 줄 (⑤)
- **BottomActionBar** — 찜 + 보조 outlined + 주 filled 3분할 (⑤ 참고 픽 상세)
- **ExpandButton** — 더보기 풀폭 outlined (③ 이전 피드백, ⑤ 참고 픽 상세)
