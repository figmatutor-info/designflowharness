## 화면 1 · 홈

### 기본 정보

- **목적:** 유료 멤버가 앱 진입 시 이번 달 미션 진행 상태와 최근 학습/자산 현황을 한눈에 확인한다
- **진입 경로:** 앱 시작 시 / 하단 탭바 "홈" 탭
- **primary 액션:** 이번 달 미션 카드 탭 → 미션 상세(화면 3) 이동
  - **카드 지정:** 화면 안에 카드형 콘텐츠가 여러 종류(미션 카드·최근 학습자료 카드·최근 스킬 카드) 있지만, primary 는 그중 **이번 달 미션 카드 1개**로 한정한다.
  - **강조 variant 필요:** 예. 미션 카드는 `MissionCard(highlight)` variant — 진행률 바 + D-day 뱃지 + 강조색 배경/보더로 다른 카드(최근 학습자료, 최근 스킬)와 시각적으로 구분한다. 나머지 카드는 기본 `Card` variant.
- **부가 액션:**
  - 최근 학습한 자료 카드 탭 (시연 제외 화면인 자료 상세로 연결되나, 본 시연에서는 화면 전환만 표시)
  - 최근 스킬 카드 탭 (스킬 라이브러리의 카드와 동일 컴포넌트 재사용, 탭 시 스킬 라이브러리로 이동)
  - 내 자산 진행 상황 요약 탭 → 내 자산(화면 4) 이동
  - 알림 아이콘 탭 (시연 제외 — 알림 목록은 PRD §6 제외 화면)
- **데이터:** 이번 달 미션(제목, 진행률, D-day), 최근 학습자료 목록, 최근 스킬 카드 목록, 내 자산 진행 요약(등록 수·판매 상태 요약)
- **필요 상태:** default, loading, empty (신규 유료 전환 직후 이번 달 미션이 아직 배정되지 않은 경우 — 미션 카드 자리에 EmptyState 표시)
- **이미지 자리:** 최근 학습한 자료 썸네일 3 (4:3). 미션 카드·최근 스킬 카드는 이미지 없음(텍스트+뱃지 중심, analysis.md UX-3 참고— 게임 일러스트 요소 배제)

### 레퍼런스 매칭

analysis.md 패턴 매칭:

- **UX 패턴 #3** (게이미피케이션 진행률 + 잠금 카드, 일러스트 요소는 배제) — 말해보카(010)에서 발견. 이번 달 미션 카드의 진행바 + D-day 뱃지 구조에 적용
- **시각 패턴 #2** (화이트 배경 + 단일 강조색 CTA) — 홀릭스(002), 말해보카(011)에서 발견. 미션 카드 강조 배경/보더 색에 적용
- **컴포넌트 패턴 #1** (하단 탭바 5개) — 크몽(005)·프립(008)·차란(012)에서 발견. 홈/스킬 라이브러리/미션/내 자산/허들링 픽 5탭에 적용

### 필요 컴포넌트

## 화면 2 · 스킬 라이브러리

### 기본 정보

- **목적:** 유료 멤버가 하이서 검증 스킬/프롬프트를 카테고리·난이도로 탐색한다
- **진입 경로:** 하단 탭바 "스킬 라이브러리" 탭 / 홈의 최근 스킬 카드 탭
- **primary 액션:** 스킬 카드 탭 → 스킬 카드 상세(PRD §6 시연 제외 화면, 본 시연에서는 화면 전환만 표시)
  - **카드 지정:** 목록의 모든 스킬 카드는 동일한 가중치를 가진다. 특정 1개 카드를 강조하지 않는다 — "primary 액션" 은 "목록 내 임의의 카드를 탭하는 행위" 자체이며, 카드 스타일은 전부 동일한 `SkillCard` 컴포넌트를 쓴다.
  - **강조 variant 필요:** 아니오. 강조가 필요한 화면(홈)과 달리, 여기서는 모든 카드가 동등해야 탐색 목적에 맞다.
- **부가 액션:**
  - 검색바 탭 (스킬명 검색)
  - 카테고리 필터 칩 선택 (AI 실무 / Figma+AI / 바이브코딩 / 자동화 / 콘텐츠 제작 / 1인 사업가)
  - 난이도 필터 칩 선택 (초급 / 중급 / 고급)
- **데이터:** 스킬 카드 목록 (제목, 카테고리 태그, 난이도, 사용 도구, 무료/유료 표시)
- **필요 상태:** default, loading, empty (필터·검색 결과 0건)
- **이미지 자리:** 이미지 없음 — 스킬 카드는 텍스트(제목·카테고리 태그·난이도·도구·무료/유료 뱃지) 중심 카드로 구성한다.

### 레퍼런스 매칭

analysis.md 패턴 매칭:

- **시각 패턴 #3** (2열 카드형 그리드) — 프립(008)에서 발견. 스킬 카드 2열 그리드 배치에 참고 (단, 카테고리 자체는 이미지 그리드가 아닌 가로 스크롤 칩으로 대체)
- **컴포넌트 패턴 #4** (세그먼트 탭/필터 칩 토글) — 홀릭스(003)·크몽(004)·말해보카(010)에서 발견. 카테고리·난이도 필터를 가로 스크롤 칩으로 구현
- **시각 패턴 #5** (숫자/순위 강조 컬러 포인트, 참고용) — 클래스101(006)에서 발견. 검색바 스타일 참고

- SkillCard (제목 + 카테고리 태그 + 난이도 뱃지 + 도구 태그 + 무료/유료 뱃지, 이미지 없음)

## 화면 3 · 미션 상세

### 기본 정보

- **목적:** 이번 달 미션 내용을 확인하고 산출물을 제출한다
- **진입 경로:** 홈의 이번 달 미션 카드 탭
- **primary 액션:** 제출하기 (파일 첨부 + 설명 작성) — 하단 고정 버튼(BottomActionBar)
- **부가 액션:**
  - 관련 스킬 카드 추천 탭 → 스킬 라이브러리 이동
  - 이전 피드백 기록 펼쳐보기
  - 제출 상태 뱃지 확인 (작성 중 / 제출 완료 / 피드백 대기 / 승인)
- **데이터:** 미션 제목·설명·마감일, 요구 산출물 목록, 제출 상태, 이전 피드백 기록, 관련 스킬 카드 추천 목록
- **필요 상태:** default, loading, submitting(제출 처리 중 — 파일 업로드), error(제출 실패)
- **이미지 자리:** 이미지 없음 — 미션 상세는 텍스트(설명·요구사항·피드백)와 파일 첨부 그리드 중심 구성. 관련 스킬 카드 추천도 화면 2와 동일하게 이미지 없음.
- **하단 고정 요소:** BottomActionBar(제출하기 1버튼, sticky) 만 사용한다. 미션 상세는 탭바 루트가 아닌 상세 화면(홈에서 push)이므로 TabBar 와 동시 배치 문제가 없다.
- **제출 확인 모달:** "제출하기" 탭 시 중앙 확인 모달(CenterModal, 취소/제출 확정 2버튼)을 거쳐 submitting 상태로 전환한다.

### 레퍼런스 매칭

analysis.md 패턴 매칭:

- **UX 패턴 #2** (Sticky 하단 액션 바) — 크몽(004)·프립(009)에서 발견. "제출하기" 버튼을 화면 최하단 고정 바로 구현
- **UX 패턴 #1** (다중 파일 선택 → 하단 sticky 확정) — 홀릭스(003)·차란(013)에서 발견. 파일 첨부 단계를 다중 선택 그리드 + "N개 선택 완료" sticky 버튼으로 구현
- **컴포넌트 패턴 #5** (중앙 확인 모달, 2버튼) — 말해보카(011)에서 발견. 제출 확정 전 확인 모달에 적용

### 필요 컴포넌트

- StatusBadge (작성 중/제출 완료/피드백 대기/승인 — 텍스트형, 미션 상세는 4단계라 세그먼트 탭 대신 뱃지 사용)
- MultiSelectGrid (파일 첨부, 선택 순서 배지)
- BottomActionBar (sticky, 제출하기 1버튼)
- CenterModal (제출 확인 다이얼로그, 취소/확정 2버튼)
- SkillCard (관련 스킬 추천, 이미지 없음)
- LoadingSpinner

## 화면 4 · 내 자산

### 기본 정보

- **목적:** 내가 만든 자료를 관리하고 판매 신청한다
- **진입 경로:** 하단 탭바 "내 자산" 탭
- **primary 액션:** 새 자산 등록
  - **배치 결정:** TabBar 유지 + 콘텐츠 상단 인라인 Button. 내 자산은 하단 탭바 루트 화면이므로 BottomActionBar(전체 폭 sticky 버튼)를 추가하면 TabBar 와 하단에서 겹친다. 따라서 TabBar 는 유지하고, "새 자산 등록" 은 화면 상단(판매 수익 요약 박스 아래, 필터 위)에 인라인 Button(secondary/outline 사이즈, 우측 정렬)으로 배치한다. analysis.md 의 플로팅 pill 버튼(컴포넌트 패턴 #2, 차란 012)은 하단 겹침 우려로 채택하지 않는다.
- **부가 액션:**
  - 필터 탭 선택 (전체 / 비공개 / 멤버 공개 / 판매 신청 중 / 판매 중)
  - 자산 카드 탭 → 자산 상세(PRD §6 시연 제외 화면, 화면 전환만 표시)
  - 판매 수익 요약 박스 확인
- **데이터:** 자산 목록(썸네일, 제목, 카테고리, 상태 뱃지, 검수 진행 상황), 판매 수익 요약
- **필요 상태:** default, loading, empty (필터 결과 0건 — 예: "판매 중" 필터에 해당 자산 없음)
- **이미지 자리:** 자산 카드 썸네일 최대 6 (1:1, 정사각) — 목록 default 상태 기준 최초 노출 카드 수

### 레퍼런스 매칭

analysis.md 패턴 매칭:

- **UX 패턴 #4** (마이페이지 그룹 리스트: 프로필/요약 박스 → 섹션형 필터 리스트) — 크몽(005)·차란(012)에서 발견. 판매 수익 요약 박스를 상단 강조 박스로, 필터를 그 아래 섹션형으로 구성
- **컴포넌트 패턴 #3** (이미지 오버레이 상태 뱃지) — 차란(014)에서 발견. 자산의 visibility/review_status 를 썸네일 좌상단 오버레이 뱃지로 표시
- **UX 패턴 #5** (빈 상태: 아이콘 + 한 줄 안내) — 홀릭스(001)에서 발견. 필터 결과 0건일 때 최소 구성 빈 상태 적용

### 필요 컴포넌트

- SummaryBox (판매 수익 요약, 강조 배경 + CTA 링크)
- FilterChip (전체/비공개/멤버공개/판매신청중/판매중 — 탭 타겟 44×44 이상)

- Button (인라인 "새 자산 등록", secondary/outline)

## 화면 5 · 허들링 픽

### 기본 정보

- **목적:** 검증된 멤버 자산을 탐색하고 구매로 연결한다
- **진입 경로:** 하단 탭바 "허들링 픽" 탭
- **primary 액션:** 픽 카드 탭 → 픽 상세 페이지(PRD §6 시연 제외 화면, 본 시연에서는 화면 전환만 표시. 미리보기·포함 내용·사용 조건·구매 버튼은 상세 화면에서 구현)
  - **카드 지정:** 스킬 라이브러리와 동일하게 목록 내 모든 픽 카드가 동등한 가중치를 가진다. 특정 카드를 강조하지 않는다.
  - **강조 variant 필요:** 아니오. 모든 카드가 동일한 `PickCard` 컴포넌트를 쓴다.
- **부가 액션:**
  - 검색바 탭
  - 카테고리 필터 칩 선택
  - 정렬 옵션 선택 (최신순 / 인기순 / 가격순)
- **데이터:** 픽 카드 목록(이미지, 제목, 제작자, 가격, 카테고리)
- **필요 상태:** default, loading, empty (카테고리 필터 결과 0건)
- **이미지 자리:** 픽 카드 이미지 최대 6 (4:3) — 목록 default 상태 기준 최초 노출 카드 수. 이미지 위 가격/카테고리 오버레이 태그 포함.

### 레퍼런스 매칭

analysis.md 패턴 매칭:

## 화면 흐름 요약

```
홈 (①)
├─ 이번 달 미션 카드 탭 (primary) → 미션 상세 (③)
├─ 최근 학습자료 카드 탭 → (시연 제외: 자료 상세)
├─ 최근 스킬 카드 탭 → 스킬 라이브러리 (②)
├─ 내 자산 요약 탭 → 내 자산 (④)
└─ 탭바 이동 → 스킬 라이브러리(②) / 내 자산(④) / 허들링 픽(⑤)

스킬 라이브러리 (②)
└─ 스킬 카드 탭 (primary) → (시연 제외: 스킬 카드 상세)

미션 상세 (③)
├─ 관련 스킬 카드 탭 → 스킬 라이브러리 (②)
└─ 제출하기 (primary) → 확인 모달 → submitting → 제출 완료 (③ 내에서 상태 갱신)

내 자산 (④)
├─ 새 자산 등록 (primary) → (시연 제외: 자산 등록 폼)
└─ 자산 카드 탭 → (시연 제외: 자산 상세)

허들링 픽 (⑤)
└─ 픽 카드 탭 (primary) → (시연 제외: 픽 상세 페이지)
```

## 컴포넌트 목록 (전체 화면 통합)

이 앱에 필요한 컴포넌트:

- **BottomTabBar** — 하단 5개 탭 (홈/스킬 라이브러리/미션/내 자산/허들링 픽), 배지 카운트 지원 (①②④⑤)
- **MissionCard** (highlight variant) — 진행률 바 + D-day 뱃지 (①)
- **Card** (기본 variant) — 최근 학습자료·최근 스킬 카드 공용 (①)
- **SkillCard** — 제목 + 카테고리 태그 + 난이도 뱃지 + 도구 태그 + 무료/유료 뱃지, 이미지 없음 (①②③)
- **AssetCard** — 썸네일 + 상태 뱃지 오버레이 + 제목 + 카테고리 (④)
- **PickCard** — 이미지 + 가격/카테고리 오버레이 태그 + 제목 + 제작자 (⑤)
- **SearchBar** — 검색 인풋, sticky top (②⑤)
- **FilterChip** — 카테고리/난이도/상태 필터, 탭 타겟 44×44 이상 필수 (②④⑤)
- **SegmentedTab** — 정렬 옵션 (⑤)
- **StatusBadge** — 텍스트형(미션 제출 상태, ③) / 이미지 오버레이형(자산 상태, ④)
- **SummaryBox** — 판매 수익 요약, 강조 배경 + CTA (④)
- **MultiSelectGrid** — 파일 첨부용, 선택 순서 배지 (③)
- **BottomActionBar** — sticky 하단 액션 바 (제출하기, ③)
- **CenterModal** — 확인 다이얼로그, 2버튼 (③)
- **Button** (primary, secondary/outline, disabled) — 전 화면 공용
- **EmptyState** — 아이콘 + 한 줄 안내 (①②④⑤)
- **LoadingSpinner** — 로딩 표시 (전 화면 공용)
