# User Flows

**작성일:** 2026-09-18 (수정: 2026-09-18 — 하단 탭바 등 가정 항목 확정 반영)
**대상:** 허들링 앱
**근거:** PRD.md §3 사용자 시나리오, design/02-structure/screens.md
**총 시나리오:** 3개

각 시나리오는 2인칭 현재형으로 서술. 화면 번호는 screens.md 참조(① 홈, ② 스킬 라이브러리, ③ 미션 상세, ④ 내 자산, ⑤ 허들링 픽).
PRD §6에 따라 시연 범위 밖 화면(스킬 카드 상세, 자산 등록 폼, 자산 상세, 허들링 픽 상세 등)이 필요한 지점은 "시연 범위 외"로 표기하고 넘어간다.

**확정: 하단 탭바.** 홈(①) · 스킬 라이브러리(②) · 내 자산(④) · 허들링 픽(⑤)은 하단 탭바 4탭으로 서로 이동한다. 미션 상세(③)는 탭바 대상이 아니며 홈의 미션 카드를 통해서만 진입한다.

## 시나리오 1 · 이번 달 학습 시작

**목적 (PRD §3 시나리오 1):** 앱을 켠 유료 멤버가 이번 달 미션을 확인하고, 관련 스킬을 탐색해 실무에 적용하기 시작한다.
**관련 화면:** 홈(①), 미션 상세(③), 스킬 라이브러리(②)

### 흐름

1. 당신은 앱을 엽니다. 홈 화면이 보이고, 상단에 이번 달 미션 카드(진행률, D-day)가 있습니다. 그 아래로 최근 학습한 자료, 최근 스킬 카드, 내 자산 진행 상황 요약, 알림이 순서대로 배열되어 있고, 화면 맨 아래에는 하단 탭바(홈 활성)가 고정되어 있습니다. (①)

2. 이번 달 미션 카드를 탭합니다 (primary 액션). 미션 상세 화면으로 이동합니다. 이 화면에는 하단 탭바가 없습니다.
   미션 제목·설명·마감일, 요구 산출물, 관련 스킬 카드 추천, 제출 상태, 이전 피드백 기록이 순서대로 보입니다. (③)

3. "관련 스킬 카드 추천" 로우에서 항목을 탭합니다. 스킬 라이브러리 화면으로 이동합니다.
   검색바 아래로 카테고리 필터, 난이도 필터, 스킬 카드 그리드, 하단 탭바(스킬 라이브러리 활성)가 보입니다. (②)

   **가정 (유지):** PRD §3은 "미션 관련 스킬 라이브러리 탐색"이라고만 서술해, 미션 상세의 어떤 요소를 탭해 스킬 라이브러리로 이동하는지는 명시하지 않는다. 여기서는 "관련 스킬 카드 추천" 로우의 항목 탭을 진입 트리거로 가정했다. (이번 확정 항목에는 포함되지 않음 — 하단 탭바로 직접 이동하는 것과는 별개의 경로다.)

4. 카테고리 필터(예: AI 실무)와 난이도 필터를 사용해 원하는 스킬 카드를 찾습니다. 검색바를 탭하면 화면을 벗어나지 않고 인기 검색어 리스트가 화면 내 상태로 펼쳐집니다 (확정: 검색 진입은 별도 화면이 아니라 화면 내 상태 전환).

5. 마음에 드는 스킬 카드를 탭합니다 (primary 액션). 스킬 카드 상세 화면으로 이동합니다.
   → **시연 범위 외** (PRD §6). 이 화면에서 프롬프트/스킬 내용을 확인하고 실무에 적용하는 것으로 시나리오를 마무리한다.

### 관련 컴포넌트

- ProgressBar (① 미션 진행률)
- 아이템 로우 (①③ 최근 자료/스킬, 관련 스킬 추천)
- Tab (② 카테고리/난이도 필터)
- SkillCard (② 그리드)
- TabBar (①② 하단 4탭)

### 예상 시간

PRD에 명시된 기준 없음 — 별도 측정치 없음.

## 시나리오 2 · 산출물 자산화

**목적 (PRD §3 시나리오 2):** 미션 수행 후 결과물을 제출하고, 피드백을 반영해 승인받은 뒤 자기 자산으로 전환하고 판매를 신청한다.
**관련 화면:** 미션 상세(③), 내 자산(④)

### 흐름

1. 당신은 미션 상세 화면에 있습니다. "제출하기" 버튼(primary 액션)을 탭하면 같은 화면 안에서 상태가 전환되며 파일 첨부 + 설명 작성 폼이 나타납니다.
   **확정:** 파일 첨부·설명 작성 폼은 별도 화면이 아니라 미션 상세 화면 내 상태 전환으로 처리한다.

2. 제출을 완료하면 제출 상태가 "제출 완료"로 바뀌고, 화면에는 AI/운영자 검수 대기 상태(submitting — dimmed 배경 + 중앙 로딩 카드)가 잠깐 표시됩니다. (③)

3. 이후 제출 상태가 "피드백 대기"로 바뀌고, 피드백이 도착하면 "이전 피드백 기록" 섹션에 반영됩니다. 당신은 피드백을 확인하고 제출물을 수정합니다. (③)

   **확정:** 재제출도 별도 화면이 아니라 같은 미션 상세 화면의 "제출하기" 버튼을 다시 탭해 진행한다.

4. 제출 상태가 "승인"으로 바뀝니다. (③)

5. 승인된 산출물을 내 자산으로 전환합니다. 당신은 하단 탭바에서 "내 자산"을 탭해 내 자산 화면으로 이동합니다.
   자산 목록, 상태 필터, 새 자산 등록 버튼, 각 자산 카드의 상태 뱃지, 판매 수익 요약, 하단 탭바(내 자산 활성)가 보입니다. (④)

   **확정:** 승인된 제출물이 자동으로 자산화되지 않는다. 사용자가 내 자산 화면의 "새 자산 등록"(primary 액션)을 직접 탭해 수동으로 전환을 시작한다.

6. "새 자산 등록"을 탭합니다. 자산 등록 폼으로 이동합니다.
   → **시연 범위 외** (PRD §6 "자산 상세 / 자산 등록 폼"). 등록 흐름 중 AI 자동 태깅/검수 로딩 모달이 표시되는 것으로 analysis.md에 기록되어 있다.

7. 등록이 완료되면 자산 상태가 "비공개"로 내 자산 화면에 나타납니다. 원한다면 판매 신청을 진행합니다(선택).

   **확정:** 판매 신청 액션 자체는 자산 상세(시연 범위 외) 화면에서 이루어진다. 내 자산 화면은 판매 신청 이후의 상태 전환 결과("판매 신청 중" → 검수 → "판매 중")만 보여준다.

### 관련 컴포넌트

- BottomCTA (③ 제출하기/재제출 공용)
- Modal (③ AI 검수 대기, ④ 등록 시 AI 자동 태깅)
- SectionHeader (③ 제출 상태·피드백 이력)
- Tab (④ 상태 필터)
- AssetCard (④ 상태 뱃지 + 검수 진행 상황 — 이미지 슬롯 fit(contain) + 파스텔 하늘색 배경)
- TabBar (④ 하단 4탭)

### 예상 시간

PRD에 명시된 기준 없음 — 별도 측정치 없음.

## 시나리오 3 · 허들링 픽 탐색

**목적 (PRD §3 시나리오 3):** 다른 멤버가 만든 검증된 자산을 둘러보고, 필요하면 구매한다.
**관련 화면:** 허들링 픽(⑤)

### 흐름

1. 당신은 하단 탭바에서 "허들링 픽"을 탭해 허들링 픽 화면에 진입합니다 (확정: 하단 탭바 네 번째 탭).
   검색바 아래로 카테고리 필터, 정렬(최신순/인기순/가격순), 픽 카드 그리드(이미지, 제목, 제작자, 가격, 카테고리), 하단 탭바(허들링 픽 활성)가 보입니다. (⑤)

2. 카테고리 필터나 정렬을 사용해 원하는 자산을 좁혀갑니다. 검색바를 탭하면 화면을 벗어나지 않고 랭크드 인기 검색어 리스트가 펼쳐집니다 (확정: 검색 진입은 화면 내 상태 전환). (⑤)

3. 마음에 드는 픽 카드를 탭합니다 (primary 액션). 허들링 픽 상세 페이지로 이동합니다.
   → **시연 범위 외** (PRD §6 "허들링 픽 상세"). PRD §5에 따르면 이 상세 페이지에는 미리보기, 포함 내용, 사용 조건, 구매 버튼이 있다.

4. (선택) 상세 페이지에서 "구매하기"를 탭해 자산을 구매합니다.
   → **시연 범위 외.** PRD §12에 결제 정산은 Phase 3 이후 범위로 명시되어 있어 구매 완료 이후 흐름은 이 시나리오에서 다루지 않는다.

### 관련 컴포넌트

- SearchBar + 랭크드 검색어 리스트 (⑤, 화면 내 상태 전환)
- Tab (⑤ 카테고리/정렬)
- PickCard (⑤ 그리드 — 이미지 슬롯 fit(contain) + 파스텔 하늘색 배경, 세로형 비율)
- TabBar (⑤ 하단 4탭)

### 예상 시간

PRD에 명시된 기준 없음 — 별도 측정치 없음.
