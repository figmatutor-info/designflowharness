# User Flows

**작성일:** 2026-09-19
**총 시나리오:** 3개

각 시나리오는 2인칭 현재형으로 서술.
화면 번호는 screens.md 참조 (①홈 ②스킬 라이브러리 ③미션 상세 ④내 자산 ⑤허들링 픽).
PRD §3 사용자 시나리오 3개(이번 달 학습 시작 / 산출물 자산화 / 허들링 픽 탐색)에 대응.

## 시나리오 1 · 이번 달 학습 시작

**목적:** 유료 멤버가 앱을 켜서 이번 달 미션을 확인하고 관련 스킬을 탐색해 실무에 적용한다 (PRD §3 시나리오 1)
**관련 화면:** 홈(①), 스킬 라이브러리(②)

### 흐름

1. 당신은 앱을 엽니다. 홈 화면이 보입니다. 상단에는 이번 달 미션 카드가
   강조색 배경과 진행률 바, D-day 뱃지로 다른 카드보다 눈에 띄게 배치되어
   있습니다. 그 아래로 최근 학습한 자료 카드와 최근 스킬 카드가 이어집니다. (①)

2. 이번 달 미션 카드를 탭합니다. 이것이 이 화면의 primary 액션입니다.
   화면이 전환되며 미션 상세로 넘어갈 수도 있지만, 지금은 먼저 관련 스킬을
   확인하고 싶어 카드 안의 "관련 스킬 카드 추천" 항목을 눈여겨봅니다.

3. 하단 탭바에서 "스킬 라이브러리" 탭을 누릅니다. 스킬 라이브러리 화면으로
   이동합니다. 상단에 검색바, 그 아래 카테고리 필터 칩(AI 실무 / Figma+AI /
   바이브코딩 / 자동화 / 콘텐츠 제작 / 1인 사업가)이 가로로 나열되어 있습니다. (②)

4. "자동화" 카테고리 칩을 탭합니다. 목록이 필터링되어 자동화 관련 스킬
   카드만 남습니다. 각 카드에는 난이도 뱃지와 무료/유료 표시가 붙어 있습니다.

5. 마음에 드는 스킬 카드를 탭합니다. 이것이 이 화면의 primary 액션입니다.
   스킬 카드 상세(시연 제외 화면)로 이동하며, 스킬을 실무에 적용할 준비를
   마칩니다.

### 관련 컴포넌트

- MissionCard (highlight variant, ①)
- BottomTabBar (①→②)
- SearchBar, FilterChip (②)
- SkillCard (②)

### 예상 시간

첫 진입 기준 약 1분 이내

## 시나리오 2 · 산출물 자산화

**목적:** 미션 수행 후 결과물을 제출하고, 피드백을 받아 수정한 뒤, 승인된 산출물을 내 자산으로 전환해 판매 신청까지 진행한다 (PRD §3 시나리오 2)
**관련 화면:** 홈(①), 미션 상세(③), 내 자산(④)

### 흐름

1. 당신은 홈 화면에서 이번 달 미션 카드를 탭합니다. 미션 상세 화면으로
   이동합니다. 미션 제목, 설명, 마감일, 요구 산출물(예: "AI 자동화 자산 1개 +
   실제 적용 사례 1개")이 보이고, 화면 최하단에는 "제출하기" 버튼이 고정되어
   있습니다. (①→③)

2. "제출하기" 버튼을 탭합니다. 이것이 이 화면의 primary 액션입니다.
   먼저 다중 선택 그리드가 나타나 결과물 파일을 여러 장 고를 수 있습니다.
   파일을 선택하면 하단에 "N개 선택 완료" 버튼이 나타납니다. (③)

3. 선택 완료 버튼을 탭하면 화면 중앙에 확인 모달이 dim 배경과 함께 뜹니다.
   "제출하시겠습니까?" 문구 아래 취소(회색)와 제출(강조색) 2버튼이 있습니다.
   제출을 탭합니다. (③)

4. 화면이 submitting 상태로 바뀌며 업로드 진행을 보여준 뒤, 제출 상태
   뱃지가 "제출 완료" 로 바뀝니다. 며칠 후 다시 들어오면 상태 뱃지가
   "피드백 대기" 를 거쳐 "승인" 으로 바뀌어 있고, 이전 피드백 기록도
   함께 확인할 수 있습니다. (③)

5. 승인된 산출물을 자산화하기 위해 하단 탭바에서 "내 자산" 탭을 누릅니다.
   내 자산 화면으로 이동합니다. 상단에 판매 수익 요약 박스가 있고, 그 아래
   필터(전체/비공개/멤버 공개/판매 신청 중/판매 중)와 자산 카드 목록이
   보입니다. 승인된 산출물이 "비공개" 상태 뱃지가 붙은 카드로 이미 목록에
   올라와 있습니다. (③→④)

6. 해당 자산 카드를 탭해 상세(시연 제외 화면)로 이동한 뒤 판매 신청을
   진행합니다. 목록으로 돌아오면 카드의 상태 뱃지가 "판매 신청 중" 으로
   바뀌어 있습니다. (④)

### 관련 컴포넌트

- MissionCard (highlight variant, ①)
- MultiSelectGrid, BottomActionBar, CenterModal (③)
- StatusBadge (텍스트형, ③ / 이미지 오버레이형, ④)
- BottomTabBar (③→④)
- SummaryBox, FilterChip, AssetCard (④)

### 예상 시간

제출까지 약 2분, 승인·판매 신청 확인까지는 별도 세션(며칠 후) 재방문 포함

## 시나리오 3 · 허들링 픽 탐색

**목적:** 다른 멤버가 만든 검증된 자산을 둘러보고, 실무에 바로 쓸 자산을 구매로 연결한다 (PRD §3 시나리오 3)
**관련 화면:** 허들링 픽(⑤)

### 흐름

1. 당신은 하단 탭바에서 "허들링 픽" 탭을 누릅니다. 허들링 픽 화면으로
   이동합니다. 상단에 검색바, 그 아래 카테고리 필터 칩과 정렬 옵션(최신순/
   인기순/가격순)이 있고, 본문에는 픽 카드 목록이 이미지 중심으로 배치되어
   있습니다. 각 이미지 위에는 가격과 카테고리 태그가 오버레이로 얹혀
   있습니다. (⑤)

2. 정렬 옵션에서 "인기순" 을 선택합니다. 목록 순서가 바뀝니다.

3. 눈에 띄는 픽 카드를 탭합니다. 이것이 이 화면의 primary 액션입니다.
   픽 상세 페이지(시연 제외 화면)로 이동합니다. 미리보기 이미지, 포함
   내용, 사용 조건, 그리고 화면 하단에 고정된 "구매하기" 버튼이 보입니다.

4. 구매 여부를 검토한 뒤, 필요하면 "구매하기" 를 눌러 구매를 진행합니다
   (구매 흐름 자체는 PRD §12 제외 사항 — 결제 정산은 Phase 3 이후).

### 관련 컴포넌트

- SearchBar, FilterChip, SegmentedTab (⑤)
- PickCard (⑤)
- BottomTabBar (⑤)

### 예상 시간

탐색부터 상세 진입까지 약 30초 이내

### 특이 사항

목록의 모든 픽 카드는 동등한 가중치를 가지며 특정 카드를 강조하지 않는다 (screens.md 화면 5 참고). 카테고리 필터 결과가 0건이면 EmptyState(아이콘 + 한 줄 안내)가 표시된다.
